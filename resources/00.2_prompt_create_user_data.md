# Prompt: Fiktive User-Account Testdaten für eine Bücherverwaltung

## Ziel

Erstelle eine csv-Datei mit insgesamt **20 fiktiven Personendatensätze** zu Personen.

---

## Allgemeine Vorgaben

- Dateiname: 05_user_data.csv
- Verwende ausschließlich **fiktive Personendaten**, aber reale Orte und Adressen
- Verwende ausschließlich **lateinische Schriftzeichen**.
- Die Ausgabe soll als **UTF-8-kompatibler Text** erfolgen.
- Verwende **Komma** als CSV-Trennzeichen.
- Verwende in der CSV-Datei eine Kopfzeile.
- Setze alle Textwerte in **doppelte Anführungszeichen**.
- Gib **keine Markdown-Tabellen** aus.
- Gib **genau drei separate CSV-Codeblöcke** aus.

---

## Spalten

```text
Akad. Titel,Vorname, Nachname, E-Mailadresse, Telefonnummer, Strasse, Hausnummer, Längengrad, Breitengrad, Postleitzahl, Ort, Land, Rolle
```

## Anforderungen

| Feld                   | Vorgabe                                                                     |
|------------------------|-----------------------------------------------------------------------------|
| Veröffentlichungsdatum | Optional, mind. 5 Personen tragen einen Titel wie `Dr.`, `Prof.` oder `PhD` |
| Telefonnummer          | Formatiere gem. RegEx `^[+][0-9 -]+$`, verwende realistische Nummernfolgen  |
| Längengrad/Breitengrad | muss zur Adresse gehören, Format: 00.000000                                 |
| E-Mailadressen         | fiktiv aber valide                                                          |
