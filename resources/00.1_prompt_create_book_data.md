# Prompt: Fiktive Bücher-Testdaten für eine Bücherverwaltung

## Ziel

Erstelle insgesamt **20 Buchtitel als CSV-Daten**. Die Bücher sollen gleichmäßig auf vier Sprachen verteilt sein:

| Sprache    | Anzahl |
|------------|-------:|
| Deutsch    |      5 |
| Englisch   |      5 |
| Spanisch   |      5 |
| Dänisch    |      5 |
| **Gesamt** | **20** |

---

## Allgemeine Vorgaben

- Verwende ausschließlich **fiktive Bücher**, **fiktive ISBNs**, **fiktive Autorinnen/Autoren** und **fiktive
  Verlagsdaten**.
- Die ISBNs sollen plausibel im **ISBN-13-Format** aufgebaut sein.
- Jede ISBN muss eindeutig sein.
- Verwende ausschließlich **lateinische Schriftzeichen**.
- Verwende keine kyrillischen, arabischen, griechischen, hebräischen, chinesischen, japanischen, koreanischen oder
  sonstigen nicht-lateinischen Zeichensätze.
- Die Ausgabe soll als **UTF-8-kompatibler Text** erfolgen.
- Verwende **Komma** als CSV-Trennzeichen.
- Verwende in jeder CSV-Datei eine Kopfzeile.
- Setze alle Textwerte in **doppelte Anführungszeichen**.
- Gib **keine Markdown-Tabellen** aus.
- Gib **genau drei separate CSV-Codeblöcke** aus.

---

# Datei 1: `buecher.csv`

## Spalten

```text
ISBN,Titel,Beschreibung,Veroeffentlichungsdatum,Auflage,Sprache,Genre
```

## Anforderungen

| Feld                   | Vorgabe                          |
|------------------------|----------------------------------|
| Veröffentlichungsdatum | ISO-Format `YYYY-MM-DD`          |
| Sprache                | ISO-Sprachcode                   |
| Auflage                | Numerischer Wert (z. B. 1, 2, 3) |
| Beschreibung           | 1 bis 2 vollständige Sätze       |
| Genre                  | Verschiedene Genres verwenden    |

---

# Datei 2: `verlage.csv`

## Spalten

```text
ISBN,Verlagsname,Webseite,Strasse,Hausnummer,Postleitzahl,Ort,Land
```

## Anforderungen

- Jeder Eintrag muss sich über die ISBN eindeutig einem Buch aus `buecher.csv` zuordnen lassen.
- Verwende fiktive Verlagsnamen.
- Die Webseiten sollen plausibel, aber fiktiv sein (z. B. mit der Domain `example.com`).
- Straße und Hausnummer müssen getrennt ausgegeben werden.
- Das Land soll als zweistelliger Ländercode angegeben werden.

---

# Datei 3: `autoren.csv`

## Spalten

```text
ISBN,AkademischerTitel,Vorname,Nachname
```

## Anforderungen

- Jeder Eintrag muss sich über die ISBN eindeutig einem Buch aus `buecher.csv` zuordnen lassen.
- Stelle sicher, dass bei mindestens **5 Büchern zwei oder mehr Autoren** zugeordnet werden.
- Das Feld `AkademischerTitel` darf leer sein oder folgende Werte enthalten:
    - `Dr.`
    - `Prof.`
    - `PhD`
    - `M.A.`

### Nachnamen mit Zusätzen

Verwende bei mindestens **8 Nachnamen** Vor- oder Zusätze wie:

### Beispiele

```text
"de la Cruz"
"van den Berg"
"von Hardenberg"
"af Lindholm"
```

Diese Zusätze müssen vollständig im Feld **Nachname** enthalten sein.
