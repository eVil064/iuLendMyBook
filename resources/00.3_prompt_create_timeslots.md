# Prompt: Time-Slots für eine Bücherverwaltung

## Ziel

Erstelle eine Liste von möglichen Zeitslots, in denen Bücher abgeholt werden können.
Diese verteilen sich über 7 Tage der Woche.

---

## Allgemeine Vorgaben

- Dateiname: 06_timeslots.csv
- Zeitangaben dürfen sich innerhalb eines Tages nicht zeitlich überschneiden
- Die Ausgabe soll als **UTF-8-kompatibler Text** erfolgen.
- Verwende **Komma** als CSV-Trennzeichen.
- Verwende in jeder CSV-Datei eine Kopfzeile.
- Setze alle Textwerte in **doppelte Anführungszeichen**.
- Gib **keine Markdown-Tabellen** aus.

## Spalten

```text
Beginn,Ende,Wochentag
```

## Anforderungen

| Feld        | Vorgabe                                            |
|-------------|----------------------------------------------------|
| Wochentag   | nummerischer Wochentag, beginnend bei 1 für Montag |
| Beginn/Ende | Format: HH:mm                                      |```
